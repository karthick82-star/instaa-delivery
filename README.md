# instaa-delivery

**INSTAA** - Multi-Device Real-Time Live Location Tracking & Hyperlocal Delivery Ecosystem.

## Features
- **Multi-Device Real-Time Live Tracking**: SSE (Server-Sent Events) live streaming for sub-50ms latency updates.
- **Customer Portal**: Product catalog, cart, checkout, and live order tracking.
- **Rider Interface**: Active delivery HUD, GPS streaming, wallet, and order acceptance.
- **Store Dashboard**: Live order management, dispatching, and incoming order notifications.
- **Admin Hub**: Fleet radar, customer and rider management, system analytics, and server health.
- **Zero External Dependencies**: Lightweight pure Node.js backend (`server.js`).

## Getting Started

### Run Locally
```bash
node server.js
```
Open `http://localhost:3000` in your browser.
